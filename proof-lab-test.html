Trust what can be verified.

A browser-based experiment with ML-DSA-65, a post-quantum digital signature algorithm standardized by NIST in FIPS 204.

Signature integrity test

The test creates a temporary key pair, signs a sample message, verifies the original, then changes the message and verifies again.

Ready. Run the test to begin.

What this test demonstrates

A valid signature can authenticate a particular message under a particular public key. Changing the signed message should cause verification to fail.

Prototype only. This does not verify $CI token transactions, audit a blockchain, or make the token quantum-resistant. The temporary secret key is kept in memory and is not displayed or intentionally transmitted or stored by this page.
