02 / Important limitations

This prototype uses the Noble Post-Quantum JavaScript library, loaded from esm.sh over the internet. Inputs are processed in this browser page and are not intentionally sent to a Corrupted Inu server. The library itself is downloaded from the external module host.

A valid signature means the supplied signature verifies for the supplied message and public key. It does not, by itself, prove the real-world identity of the signer. Never paste a secret/private key here.
